# Арифметические, логические и операторы сравнения

```go
*    /    %    <<    >>    &    &^
+    -    |    ^
==   !=   <    <=    >     >=
&&
||
```

- Логические операторы имеют пять уровней приоритета исполнения
- Можно заключать выражения в скобки
- % – только для целых чисел

---

Если результат арифметической операции имеет больше битов, чем может быть представлено типом результата, мы говорим о переполнении (overflow).

При этом старшие биты, которые не помещаются в результате, молча отбрасываются:

```go
var u uint8 = 255
fmt.Println(u, u+1, u*u) // "255 0 1"

var i int8 = 127
fmt.Println(i, i+1, i*i) // "127 -128 1”
```

# Операции сравнения

```go
==  равно
!=  не равно
<   меньше чем
<=  меньше или равно
>   больше чем
>=  больше или равно
```

- int, float, string являются сравниваемыми -> упорядочиваемыми
- Составные типы нельзя сравнивать/упорядочивать
- <span><a href = https://pkg.go.dev/reflect#DeepEqual>reflect.DeepEqual</a></span> сравнивает составные типы

# Унарные операторы

## Оператор +x

- Для целых чисел эквивалентен 0+x

## Оператор -x

# Побитовые бинарные операторы

```go
&   Побитовое И
|   Побитовое ИЛИ
^   Побитовое исключающее ИЛИ
&^  Сброс бита (И НЕ)
<<  Сдвиг влево
>>  Сдвиг вправо
```

- При использовании ^ в качестве унарного префиксного оператора он представляет собой побитовое отрицание или дополнение
- В выражении z = х &^ у каждый бит z равен 0, если соответствующий бит у равен 1
- В противном случае он равен соответствующему биту х.

# Побитовые сдвиги

```go
x := 10
n := 2
y := x >> n                             // сдвиг вправо на n бит
fmt.Printf("%08b, %08b, %[2]v\n", x, y) // 00001010, 00000010, 2
y = x / int(math.Pow(2.0, float64(n)))
fmt.Printf("%08b, %08b, %[2]v\n", x, y) // 00001010, 00000010, 2
y = x << n
fmt.Printf("%08b, %08b, %[2]v\n", x, y) // 00001010, 00101000, 40
y = x * int(math.Pow(2.0, float64(n)))
fmt.Printf("%08b, %08b, %[2]v\n", x, y) // 00001010, 00101000, 40
```

# int vs uint

```go
fruits := []string{"apple", "banana", "orange"}
for i := len(fruits) - 1; i >= 0; i-- {
    fmt.Println(fruits[i]) // "orange", "banana", "apple"
}
```

- len возвращает int

## В случае c uint

- i >= 0 всегда
- После третьей итерации i-- делает i равной, например, 2^64-1
- compile error после третьей итерации: index out of range

# Запись чисел

Числа могут быть записаны как:
- Восьмеричные, если начинаются с 0 (0777)
- Шестнадцатеричные, если начинаются с 0x (0xC0FFEE)

## Глаголы вывода

```go
o := 0777
fmt.Printf("%d %[1]o %#[1]o\n", o) // 511 777 0777
x := int64(0xC0FFEE)
fmt.Printf("%d %[1]x %#[1]x %#[1]X\n", x) // 12648430 c0ffee 0xc0ffee 0XC0FFEE
```

- Через fmt можно контролировать основание и и формат вывода с помощью %d, %o, %x
- [1] говорит fmt использовать первый (уже существующий) аргумент для вывода
- `#` говорит fmt включить в вывод префиксы 0, 0x или 0X

# Руны

```go
latin := 'z'
sanskrit := 'ऒ'
tab := '\t'
fmt.Printf("%d %[1]c %[1]q\n", latin)    // 122 z 'z'
fmt.Printf("%d %[1]c %[1]q\n", sanskrit) // 2322 ऒ 'ऒ'
fmt.Printf("%d %[1]q\n", tab)            // 9 '\t'
```

- Руны пишутся в одинарных кавычках
- Можно писать любую кодовую точку Unicode или нумерические escape последовательности
- Печатаются с помощью %c или %q (с кавычками)

## xyz.VectorLength

```go
// VectorLength calculates the length of the vector from 0,0,0 to vector
func VectorLength(vector geom.Coord) float64 {
	return math.Sqrt(vector[0]*vector[0] + vector[1]*vector[1] + vector[2]*vector[2])
}
```

# Строки

---

- Строки – неизменяемые последовательности байтов
- Текст – последовательность рун
- len возвращает число байтов, не рун
- Операция индексации s[i] получает i-ый байт строки s, не i-ый символ

```go
s := "Hello, 世界"
fmt.Println(len(s))		// 13
fmt.Println(s[0], s[8])	// 72 184
```

---

# Подстроки

Операция s[i:j] генерирует новую строку, состоящую из байтов оригинальной строки, начиная с i-го и заканчивая, без включения, j-ым байтом.

```go
fmt.Println(s[0:5]) // Hello
```

Если i и j опущены, то i=0, j=len(s)

```go
fmt.Println(s[:5]) // Hello
fmt.Println(s[7:]) // 世界
fmt.Println(s[:])  // Hello, 世界
```

---

# Объединение строк

```go
fmt.Println(s[:7] + "World!") // "Hello, Wolrd!"
```

- Невозможно изменить последовательность байтов в существующей строке
- Можно присвоить новое значение существующей переменной строкового типа

```go
s := "foo"
foo := s
s += " bar"
fmt.Println(foo) // foo
fmt.Println(s)   // foo bar
```

# От ASCII к UTF-8

ASCII – American Standart Code for Information Interchange

- Использует 7 бит для представления 128 символов
- Английский алфавит, строчные и заглавные
- Иные символы

## Недостатки

- Поддерживает только английский алфавит

---

# Unicode

- Представляет 120000 символов
- Поддерживает 100 языков

## Недостатки

Большинство компьютерочитаемого текста – это ASCII, которому нужно всего 8 бит для кодирования одного символа.

- Кодирует символы в int32 всегда

---

# UTF-8

Разработан Ken Thompson и Rob Pike – авторами Go, в 1992, стал стандартом.

- Кодирует Unicode в кодовые точки переменной длины

## Использует

- От 1 до  байт для представления каждой руны
- 1 байт для представления рун ASCII
- 2-3 байта для большинства распространенных рун

---

Биты высшего порядка первого байта указывают на количество последущих бит:

- 0 указывает на следующие 7 бит ASCII, что кодируют руну по стандарту ASCII
- 110 говорит о том, что руна занимает 2 байта; второй байт начинает с 10
- Другие руны кодируются аналогично

<br>

```
0xxxxxx									руны 0-127	(ASCII)
110xxxxx 10xxxxxx						128-2047
1110xxxx 10xxxxxx 10xxxxxx				2048-65535
11110xxx 10xxxxxx 10xxxxxx 10xxxxxx		65536-0x0ffff
```

---

Управляющие последовательности Unicode в строковых литералах Go позволяют указывать символы
Unicode с помощью их числового кода:

```go
s := "美好的"
fmt.Printf("% x\n", s)
fmt.Printf("%+q\n", s) 
fmt.Printf("%s\n", s)
```

## Вывод

<br>

```
e7 be 8e e5 a5 bd e7 9a 84

"\u7f8e\u597d\u7684"

美好的
```

# Пакет unicode/utf8

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	buf := []byte("Hello, 世界")
	fmt.Println("bytes =", len(buf))
	fmt.Println("runes =", utf8.RuneCount(buf))
}
```

## Вывод

<br>

```
bytes = 13
runes = 9
```
